# Deploying to Render

## What the free plan can and cannot do
| | Free plan | Effect on this site |
|---|---|---|
| Web service | Sleeps after 15 min idle; ~30-60 s to wake | First visitor after a quiet spell waits. Live chat drops when it sleeps. |
| **Disk** | **None — files are wiped on every deploy and restart** | **Uploaded customer artwork, proofs, delivered files and portfolio/blog photos are LOST.** |
| PostgreSQL | Free database **expires after 30 days** | Orders/accounts are deleted unless you upgrade or export first. |
| Key Value (Redis) | Free, not persisted | Fine (only live chat uses it). |

Free is fine for a **demo/test**. For real customers upgrade: web service to **Starter** (+ a 1 GB disk mounted at `/app/private_media` and another at `/app/media`) and the database to a paid plan. Disks need the app to write as root-owned mounts; if you hit "permission denied" on uploads, tell me and I'll adjust the Dockerfile.

## Steps
1. Merge the branch into `main` (or deploy the branch directly).
2. Render Dashboard → **New → Blueprint** → select this GitHub repo → it reads `render.yaml`.
3. Fill in the prompted values:
   - `SITE_URL` — `https://<your-service>.onrender.com` (or your own domain)
   - `ALLOWED_HOSTS` — your custom domain if you have one, otherwise any placeholder like `example.com` (the onrender.com host is added automatically)
   - `CSRF_TRUSTED_ORIGINS` — `https://<your-service>.onrender.com` (and your domain)
   - `ADMIN_EMAIL`, `ADMIN_PASSWORD` — your first admin login
   - `STAFF_NOTIFY_EMAIL` and the `EMAIL_*` values (Gmail needs an App Password)
4. Deploy. Migrations and the first admin are created automatically on boot (`RUN_MIGRATIONS`, `RUN_SEED`).
5. Open `https://<your-service>.onrender.com/console/`, sign in, change the password (Settings → My account), then add pricing/portfolio/social links.

## Custom domain
Render → your service → Settings → Custom Domains → add the domain, create the DNS record Render shows, then add the domain to `ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS` and `SITE_URL`. HTTPS is automatic.

## Notes
- `SECRET_KEY` is generated by Render. `SECURE_HSTS_SECONDS` starts at 0; raise to `31536000` after HTTPS is confirmed.
- Demo content is not loaded in production. Add real photos from the console.
- Updates: push to the connected branch; Render redeploys and migrates automatically.
